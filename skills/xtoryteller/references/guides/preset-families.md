# Preset Families

Use this file when the user wants a strong visual direction, wants to compare recognizable looks, or says they do not know what style they want yet.

## Rule

Start from a preset family before inventing ad-hoc styling. The preset should drive:

- the reusable theme slug
- the primary layout motif
- the background treatment
- the decorative primitives, especially `edge-rail` and `chapter-nav`

## Mood Mapping

- `confident`: `bold-signal`, `electric-studio`, `dark-botanical`
- `energetic`: `creative-voltage`, `neon-cyber`, `split-pastel`
- `calm`: `notebook-tabs`, `paper-and-ink`, `swiss-modern`
- `inspired`: `dark-botanical`, `vintage-editorial`, `pastel-geometry`

## Anti-Generic Rules

- Do not present three previews that only differ by palette.
- Do not default to generic hero layouts when a stronger motif exists.
- Do not use default UI font stacks as the display face.
- Do not describe a preset as “modern” without naming the actual family and motif choices.
